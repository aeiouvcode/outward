# OUTWARD

A calm tile puzzle. Every tile points somewhere. Tap one whose path to the edge is clear and it slides away. Tap one that's blocked and you lose a heart. Plan the order and clear the board.

- Web: https://aeiouvcode.github.io/outward/ (one self-contained index.html, no network requests, strict CSP)
- Godot: https://aeiouvcode.github.io/outward/godot/

Hold anywhere on the board for a hint. Three hearts, three hints per level. Every board can be cleared.

Original game. Built from scratch, inspired by the tap-to-clear arrow puzzle genre.
